# Catalog index — every shuttle we have, and its status

Complete enumeration of the Hammond and Blickensderfer type catalogs in
hand, with each entry's import status. Both tables are generated by
`gen_catalog_index.py`, so the counts here cannot drift from the code.

The denominators are real but come from different places: Hammond's is
its catalog's own printed Numerical Index, so it covers the whole
catalog whether or not a page was ever read. Blickensderfer prints no
such index, so its denominator is every entry the page scans actually
contain — a real count of what is in hand, not of what the company
made.

See [`LAYOUT_TRANSCRIPTION.md`](LAYOUT_TRANSCRIPTION.md) for the method,
the judgement calls, and why the held entries are held.

---

## Hammond

**258 of 346 catalogued shuttles are covered (74%)** — 22 held on an unresolved character,
66 not yet transcribed.

Status meanings:

- **imported** — this shuttle's layout is available, under the named preset.
  Note most entries differ from a covered one only in TYPEFACE (Small/
  Medium/Large Roman, Gothic, Italic, Script, Caps and Small Caps), which
  is a font choice, not a layout — so one preset legitimately covers many
  shuttles.
- **held** — read, but one character will not resolve from the scan.
- **todo** — not yet transcribed. The note gives keyboard / language /
  variant, which is what determines whether it needs a new layout.

The largest single gap is **per-language layouts on the UNIVERSAL
keyboard**: every language layout imported so far is Ideal, but the
catalog carries Universal equivalents for German, Russian, Italian,
French, Swedish-Finnish, Spanish, Dutch and more.

Page numbers are the 1915 catalog's own printed page. Entries with no
page appear in the 1920 catalog, which numbers beyond the 1915 index.
