# Mignon Index Holder

A companion accessory for the Mignon type element - not itself generated by
this pipeline. It holds the printed-out legend (the reference card showing
which character sits at which drum position) alongside the printed Mignon
element, since a struck element carries no visible legend of its own once
mounted.

Modeled in Fusion 360; STL and STEP exports are checked in under
`docs/mignon_index_holder/`:

- `Mignon Index Holder v16.stl` - print-ready mesh
- `Mignon Index Holder v16.stp` - STEP source, for further CAD edits

This is a v1-era CAD accessory, unrelated to the config/lib parametric
pipeline that builds the type element itself - there is no `config/`/`lib/`
counterpart and none is planned.

This page (and any other accessory writeups like it) is expected to move
into a proper static docs site in a future PR - see the repo's project
notes.
