Type Elements

Typewriter type elements, from any font.

Pick a machine, choose a typeface, arrange the keyboard, and get a watertight STL of a working type element - a Selectric typeball, a Blickensderfer wheel, a Hammond shuttle - ready for a resin printer.

What’s new - v5

The app is the new interface: settings grouped by task, every font shown in its own typeface, the keyboard layout drawn in the real font with missing characters flagged, live build logs and a 3D preview. Today it drives the engine on your own computer (the page walks you through starting it). A no-install version that runs entirely in your browser is close: v4’s own code already builds a full Selectric element in a tab, matching the native output exactly, and with parallel workers it finishes faster than native. Read about v5 · Performance · Engine API for anyone who wants to build their own interface.
